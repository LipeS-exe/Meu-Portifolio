## Sobre o Projeto

Este projeto nasceu com o objetivo de dar destaque estratégico ao meu perfil no **GitHub** (`@LipeS-exe`), funcionando como a vitrine principal para o ecossistema de aplicações que estou construindo até **janeiro de 2027**.

Por se tratar de uma **Landing Page**, o foco principal é unir **carregamento instantâneo**, **responsividade** e uma **experiência visual memorável** — transformando a navegação entre projetos em algo fluido e interativo.

---

## Destaques Técnicos

- **Design System no Figma:** Interface previamente prototipada no Figma antes da primeira linha de código, garantindo consistência visual, hierarquia tipográfica e identidade própria.
- **Coreografia de Animações com GSAP:** Primeiro contato prático com a **GreenSock Animation Platform (GSAP)**, explorando sua curva de aprendizagem para criar transições de entrada, timelines sincronizadas e micro-interações em 60 FPS como o grande diferencial da página.
- **Gerenciamento Moderno com pnpm:** Primeira adoção do **pnpm** no fluxo de desenvolvimento, aproveitando seu armazenamento endereçável por conteúdo para instalações mais rápidas, economia de disco e uma estrutura de dependências rigorosa e organizada.

## Stack Tecnológica

| Tecnologia                | Função no Projeto                                                  |
| :------------------------ | :------------------------------------------------------------------- |
| **Vue.js 3 + Vite** | Arquitetura reativa baseada em componentes e build ultra-rápido     |
| **Tailwind CSS**    | Estilização utilitária ágil, responsiva e de fácil manutenção |
| **GSAP**            | Motor de animações avançadas, timelines e interatividade fluida   |
| **Figma**           | Prototipação de alta fidelidade e planejamento de UI/UX            |
| **pnpm**            | Gerenciamento de pacotes otimizado para velocidade e organização   |

## Como Executar Localmente

Certifique-se de ter o **Node.js** e o **pnpm** instalados em sua máquina.

```bash
# 1. Clone o repositório
git clone [https://github.com/LipeS-exe/Meu-Portfolio.git](https://github.com/LipeS-exe/Meu-Portfolio.git)

# 2. Acesse o diretório do projeto
cd Meu-Portfolio

# 3. Instale as dependências com pnpm
pnpm install

# 4. Inicie o servidor de desenvolvimento
pnpm dev
```

Para gerar a build otimizada de produção:

```bash
pnpm build
```
